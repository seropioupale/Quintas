# Entrenador del Círculo de Quintas

Juego web para aprender y practicar el círculo de quintas. Se puede añadir a la pantalla de inicio del móvil y funciona sin conexión.

Abrir: https://seropioupale.github.io/Quintas/

Sonido de piano: muestras Salamander Grand Piano (Yamaha C5) de Alexander Holm, licencia CC BY 3.0.
